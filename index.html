Bắt đầu Mở repo

1) Chỉ định tập ảnh

Bạn có thể nhập đường dẫn tới folder (Google Drive public link) hoặc bấm Mở Colab để chạy xử lý trên Colab/Local.

Lưu ý: GitHub Pages là static — việc xử lý ảnh cần chạy ở đâu đó (Local/Colab/Server). Bạn có thể dùng Colab (đề xuất) hoặc host một Flask API.

2) Kết quả vừa xử lý

Sau khi xử lý xong, trang sẽ cố gắng tải kết quả từ endpoint bạn cấu hình (ví dụ: /results.json).

  • Tùy chỉnh threshold tương đồng (slider) và live preview thay đổi.
  • So sánh 2 ảnh side-by-side (diff view).
