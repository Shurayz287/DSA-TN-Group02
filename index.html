Dọn ảnh trùng — Chỉ vài bước đơn giản

Dán link Google Drive chứa folder ảnh (public), nhấn Run in Colab để mở notebook đã chuẩn bị sẵn — notebook sẽ mount Drive của bạn, xử lý và trả về kết quả.

⬇️ Tải notebook (.ipynb) 📦 Tải repo ZIP

Cách dùng nhanh

  1. Chuẩn bị folder ảnh → Share → Anyone with link (public).
  2. Copy link folder vào ô trên (hoặc click Run in Colab rồi dán trong notebook).
  3. Mở Colab rồi bấm Run (hoặc Run all). Notebook sẽ mount Drive, tải dữ liệu, xử lý và upload kết quả vào Drive của bạn.

Gợi ý: nếu share folder không tải được, nén folder thành zip rồi share file zip public (ổn định hơn).

Giải thích ngắn về pipeline

Mục tiêu: tìm và gom các ảnh trùng hoặc gần giống (near-duplicate), xuất kết quả dạng:

  • Trích xuất embedding cho mỗi ảnh (mô hình CNN / feature extractor).
  • Tính toán khoảng cách / cosine similarity để nhóm ảnh gần nhau (duplicates).
  • Sinh ảnh minh hoạ t-SNE 2D để visualize các nhóm và trùng lặp.
  • Xuất folder ảnh đã clean (bỏ duplicates theo logic bạn chọn) và file ZIP.

Trong notebook đã đặt sẵn: cell đầu sẽ đọc `?drive=...` (nếu có), mount Drive và dùng biến drive_link để tải folder. Mình đã chuẩn hoá cell đó cho bạn (xem hướng dẫn ở dưới).
