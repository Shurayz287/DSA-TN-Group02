Dọn ảnh trùng — Chỉ vài bước đơn giản

Công cụ giúp tìm và loại bỏ ảnh trùng lặp trong dataset ảnh của bạn. Chọn một trong các cách dưới đây để bắt đầu:

▶ Run in Colab Mở notebook trực tiếp 📂 Mở Repository Xem code trên GitHub 📦 Tải về Local Download ZIP để dùng offline

Cách dùng nhanh

  1. Chuẩn bị folder ảnh trên Google Drive → Share → Anyone with link (public).
  2. Nhấn Run in Colab để mở notebook trên Google Colab.
  3. Trong notebook: chạy tất cả cells, notebook sẽ hỏi link Google Drive của bạn.
  4. Dán link folder ảnh khi được hỏi, tool sẽ tự động xử lý và trả kết quả.

Gợi ý: nếu share folder không tải được, nén folder thành zip rồi share file zip public (ổn định hơn).

Giải thích ngắn về pipeline

Mục tiêu: tìm và gom các ảnh trùng hoặc gần giống (near-duplicate), xuất kết quả dạng:

  • Trích xuất embedding cho mỗi ảnh (mô hình CNN / feature extractor).
  • Tính toán khoảng cách / cosine similarity để nhóm ảnh gần nhau (duplicates).
  • Sinh ảnh minh hoạ t-SNE 2D để visualize các nhóm và trùng lặp.
  • Xuất folder ảnh đã clean (bỏ duplicates theo logic bạn chọn) và file ZIP.

Notebook đã được chuẩn bị sẵn, chỉ cần mở và chạy. Tất cả dependencies sẽ được tự động cài đặt.
